# Descripcion del caso
El presente proyecto propone el desarrollo de un sistema de información destinado a la gestión de una farmacia o cadena de farmacias que cuenta con una o más sucursales.  
El sistema permitirá administrar la información correspondiente a las sucursales, incluyendo sus datos de identificación, dirección, localidad, medios de contacto y horarios de atención. También permitirá asociar los empleados a las distintas sucursales y registrar sus datos personales, el rol que desempeñan y su horario laboral.  
Los empleados podrán desempeñar diferentes roles, entre ellos cajero, farmacéutico y personal de seguridad. En el caso de los farmacéuticos, se registrará además su matrícula profesional. El sistema contempla la Dirección Técnica de las sucursales, registrando el farmacéutico que la ejerce y las fechas correspondientes al inicio y finalización de dicha función.  
Asimismo, el sistema permitirá administrar los productos comercializados por la farmacia, registrando su identificación, nombre, descripción, precio y tipo de producto. Se llevará un control del stock disponible, permitiendo diferenciar las cantidades de cada producto según la sucursal a la que pertenecen.  
El sistema también permitirá registrar a los clientes y las compras que estos realicen. Cada compra estará asociada a un cliente y permitirá registrar la fecha, el monto total, el método de pago utilizado y el empleado que realizó o atendió la operación.  
Cada compra contará con un detalle de los productos adquiridos, registrando para cada uno la cantidad y el precio unitario correspondiente al momento de la operación. De esta manera, se conservará el valor histórico de los productos vendidos, evitando que una modificación posterior del precio afecte la información de compras realizadas anteriormente.  
El sistema tendrá como finalidad centralizar y organizar la información necesaria para facilitar la gestión de las sucursales, empleados, productos, stock, clientes y operaciones de venta de la cadena de farmacias.
