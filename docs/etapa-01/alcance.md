# Alcance del sistema
El sistema abarca la gestión de la información y de las operaciones principales relacionadas con una farmacia o cadena de farmacias y sus sucursales.  
Dentro del alcance del sistema se contempla:  
- Registrar y administrar la farmacia o cadena.  
- Registrar y consultar las sucursales pertenecientes a la cadena.  
- Registrar los datos de dirección y localidad de cada sucursal.  
- Registrar los datos de contacto de las sucursales.  
- Registrar y consultar los horarios de atención de las sucursales.  
- Asociar empleados a las distintas sucursales.  
- Registrar los datos identificatorios de los empleados.  
- Registrar el rol desempeñado por cada empleado.  
- Registrar el horario laboral de los empleados.  
- Registrar farmacéuticos y su matrícula profesional.  
- Administrar la Dirección Técnica de las sucursales.  
- Registrar los productos comercializados.  
- Clasificar los productos según su tipo.  
- Registrar y actualizar los precios de los productos.  
- Administrar el stock de productos correspondiente a cada sucursal.  
- Registrar y consultar clientes.  
- Registrar las compras realizadas por los clientes.  
- Registrar el empleado que realiza o atiende cada compra.  
- Registrar el método de pago utilizado en cada compra.  
- Registrar el detalle de los productos incluidos en cada compra.  
- Conservar el precio unitario histórico de los productos en cada compra.

El proyecto se limitará a la gestión de la información y operaciones mencionadas, sin abarcar otros procesos administrativos, contables o financieros que no formen parte del alcance definido para el sistema.
