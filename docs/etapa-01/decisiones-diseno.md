# 1. Introducción

Elegimos realizar este trabajo sobre la gestión de una farmacia o cadena de farmacias porque consideramos que es un caso adecuado para aplicar los conceptos de bases de datos y modelado de información.

Una farmacia maneja una gran cantidad de datos que se encuentran relacionados entre sí, como:

- Sucursales.
- Empleados.
- Productos.
- Proveedores.
- Stock.
- Clientes.
- Compras.
- Métodos de pago.

Esto permite representar diferentes tipos de relaciones y reglas de negocio dentro de una misma organización.

## ¿Por qué una farmacia?

La existencia de varias sucursales hace necesario organizar la información de manera centralizada y estructurada. Por ejemplo, es importante poder conocer qué empleados trabajan en cada sucursal, qué productos están disponibles y cuál es el stock correspondiente a cada una.

Además, las operaciones de venta requieren relacionar distintos datos, como el cliente, el empleado que realiza la operación, los productos adquiridos, las cantidades, los precios y el método de pago utilizado.

Otro aspecto importante es la necesidad de conservar información histórica. Por ejemplo, si el precio de un producto cambia, el sistema debe mantener el precio que tenía al momento de una compra anterior. Esto demuestra la importancia de diseñar correctamente las relaciones y los datos que forman parte de la base.

## Aplicación de conceptos de bases de datos

Este caso permite trabajar con diferentes entidades, relaciones, cardinalidades y reglas de negocio. Por ejemplo, un producto puede estar disponible en varias sucursales, una compra puede incluir varios productos y un empleado puede atender múltiples compras.

También permite analizar qué datos son obligatorios, cuáles pueden ser opcionales y qué restricciones deben cumplirse para mantener la integridad de la información.

Por estos motivos, consideramos que la gestión de una cadena de farmacias es un escenario realista y completo para desarrollar este trabajo. Su variedad de información y la relación entre sus diferentes componentes permiten aplicar de manera práctica los conceptos de modelado y diseño de bases de datos, buscando que la información se encuentre organizada, relacionada y disponible para facilitar la gestión del negocio.
